# Ohm's Law Visualizer

## What it does
Basically, it gives you 2 options: first is series and the other is parallel. So, after selecting your option, you get to add resistance. Then, it calculates the total resistance and plots a V-I graph for that resistance, where the voltage constantly rises from 0 to 100 with a step of 5, and the current changes accordingly. It then plots a straight line which passing through origin and takes the plot into a JPG image format for me.

## How to run
pip install matplotlib numpy
python main.py6
